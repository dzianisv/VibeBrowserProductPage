# Success Metric

Task is done when **opening `https://www.vibebrowser.app/mcp` and
`https://www.vibebrowser.app/mcp-stdio` in a fresh browser** produces **copyable,
correct remote MCP setup for the documented agents, plus a clear local-only
privacy alternative that uses no remote relay** in **the deployed Vibe Browser product
site**.

Not done at: static routes compiling, CI green, preview deployment, or a merged PR.
